# 页面分组展示清单 v1（单股分析）

## 1. 目标

将单股分析结果按页面区块组织，统一字段归位与取值优先级，避免 UI 层字段混用。

适配来源：

- `raw_result`（AI 结构化结果）
- `analysis_context_snapshot.enhanced_context`（技术/实时/筹码上下文）

## 2. 全局取值优先级（必须遵守）

1. 日线与 MA：优先 `enhanced_context.today`（或 dashboard 的 price_position）
2. 实时量比/换手/市值：优先 `enhanced_context.realtime`
3. 策略点位：`dashboard.battle_plan.sniper_points`
4. AI结论：`dashboard.core_conclusion` + `raw_result` 顶层
5. 回退策略：字段缺失时显示 `--`，不做猜测填充

---

## 3. 页面分组

## 3.1 顶部总览卡片（首屏）

1. `AI评分` ← `raw_result.sentiment_score`
2. `AI趋势` ← `raw_result.trend_prediction`
3. `AI建议` ← `raw_result.operation_advice`
4. `AI置信度` ← `raw_result.confidence_level`
5. `分析时涨跌` ← `raw_result.change_pct`（无则 `enhanced_context.realtime.change_pct`）
6. `现价` ← `raw_result.current_price`（无则 `enhanced_context.realtime.price`）

## 3.2 技术结构面板

1. `MA5/MA10/MA20` ← `dashboard.data_perspective.price_position.ma5/ma10/ma20`（无则 `enhanced_context.today.ma5/ma10/ma20`）
2. `均线排列结论` ← `dashboard.data_perspective.trend_status.ma_alignment`（无则 `enhanced_context.ma_status`）
3. `趋势分` ← `dashboard.data_perspective.trend_status.trend_score`
4. `乖离率(MA5)` ← `dashboard.data_perspective.price_position.bias_ma5`
5. `乖离状态` ← `dashboard.data_perspective.price_position.bias_status`
6. `支撑位/压力位` ← `dashboard.data_perspective.price_position.support_level/resistance_level`

## 3.3 量能与筹码面板

1. `量比` ← `dashboard.data_perspective.volume_analysis.volume_ratio`（无则 `enhanced_context.realtime.volume_ratio`）
2. `量能状态` ← `dashboard.data_perspective.volume_analysis.volume_status`
3. `换手率` ← `dashboard.data_perspective.volume_analysis.turnover_rate`（无则 `enhanced_context.realtime.turnover_rate`）
4. `量能解读` ← `dashboard.data_perspective.volume_analysis.volume_meaning`
5. `获利盘` ← `dashboard.data_perspective.chip_structure.profit_ratio`（无则 `enhanced_context.chip.profit_ratio`）
6. `平均成本` ← `dashboard.data_perspective.chip_structure.avg_cost`（无则 `enhanced_context.chip.avg_cost`）
7. `集中度` ← `dashboard.data_perspective.chip_structure.concentration`（无则 `enhanced_context.chip.concentration_90`）
8. `筹码健康度` ← `dashboard.data_perspective.chip_structure.chip_health`

## 3.4 策略点位面板

1. `理想买入` ← `dashboard.battle_plan.sniper_points.ideal_buy`
2. `次级买入` ← `dashboard.battle_plan.sniper_points.secondary_buy`
3. `止损位` ← `dashboard.battle_plan.sniper_points.stop_loss`
4. `止盈位` ← `dashboard.battle_plan.sniper_points.take_profit`
5. `建议仓位` ← `dashboard.battle_plan.position_strategy.suggested_position`
6. `入场计划` ← `dashboard.battle_plan.position_strategy.entry_plan`
7. `风控计划` ← `dashboard.battle_plan.position_strategy.risk_control`
8. `行动清单` ← `dashboard.battle_plan.action_checklist`

## 3.5 情报与风险面板

1. `最新情报` ← `dashboard.intelligence.latest_news`
2. `风险提示列表` ← `dashboard.intelligence.risk_alerts`
3. `正向催化` ← `dashboard.intelligence.positive_catalysts`
4. `业绩展望` ← `dashboard.intelligence.earnings_outlook`
5. `情绪摘要` ← `dashboard.intelligence.sentiment_summary`

## 3.6 结论与解释面板

1. `一句话结论` ← `dashboard.core_conclusion.one_sentence`
2. `信号标签` ← `dashboard.core_conclusion.signal_type`
3. `空仓建议` ← `dashboard.core_conclusion.position_advice.no_position`
4. `持仓建议` ← `dashboard.core_conclusion.position_advice.has_position`
5. `综合摘要` ← `raw_result.analysis_summary`
6. `关键要点` ← `raw_result.key_points`
7. `风险警示` ← `raw_result.risk_warning`
8. `买入/观望理由` ← `raw_result.buy_reason`

## 3.7 底部元数据面板

1. `QueryID` ← 任务上下文
2. `分析时间` ← 任务上下文
3. `报告类型` ← 任务上下文
4. `数据来源说明` ← `raw_result.data_sources`
5. `是否搜索` ← `raw_result.search_performed`
6. `行情快照` ← `raw_result.market_snapshot`

---

## 4. 数据质量与异常展示规则

1. 任一关键字段缺失显示 `--`，不做猜测
2. 当存在口径冲突（如量比来源不一致）时：
   - 以优先级高的数据源展示
   - 在字段旁显示 `来源标签`（如 `realtime/tencent`）
3. 当 `high < low` 等异常出现时：
   - 前端不直接纠正价格
   - 显示 `数据异常` 标记并记录日志

## 5. 单位与格式规范

1. 价格：元（保留 2 位）
2. 百分比：`xx.xx%`
3. 量比：`x.x`（倍）
4. 市值/成交额：亿或万亿（中文单位）
5. 列表字段（风险、催化、清单）：逐条展示，不拼成长句

## 6. 验收标准（UI层）

1. 各分组字段可稳定渲染，不因某字段缺失导致整块报错
2. 同一字段来源唯一，不跨组重复冲突
3. 样本 `601899_20260209` 页面展示值应与原始结构化结果一致
4. 用户可在不展开原始 JSON 的情况下读完整决策链
