# 规则映射表 v1（对标 daily_stock_analysis → 当前项目）

## 1. 文档目标

将 `daily_stock_analysis` 中可复用的单股结论规则，映射到当前项目（`读取股票当天数据`）的字段与计算链路。
本版本只定义 **字段、公式、阈值、映射位置**，不涉及代码改动。

## 2. 数据口径约定（必须先统一）

- 日线口径：用于 MA5/10/20、趋势、量比、MACD、RSI、支撑压制。
- 分钟/Tick 口径：用于盘中资金流、OFI、VWAP、分钟 MA。
- 禁止混用：日线 MA 结论不能直接用盘中分钟价替代收盘口径。
- 建议输出时显式标注：
  - `日线截至: YYYY-MM-DD`
  - `盘中截至: YYYY-MM-DD HH:MM`

## 3. 对标来源与当前落点

- 对标规则主文件：
  - `daily_stock_analysis/src/stock_analyzer.py`
  - `daily_stock_analysis/data_provider/base.py`
  - `daily_stock_analysis/src/core/pipeline.py`
- 当前项目建议落点：
  - 日线特征构建：`stock_analysis/ui/future_features.py` 中 `_build_daily_trend`
  - 新增规则引擎：建议 `stock_analysis/analysis/trend_signal.py`
  - AI 上下文注入：`stock_analysis/ui/future_features.py` 中 `_build_context`

## 5. 公式与阈值明细

### 5.1 趋势与均线排列

- 基础均线：
  - `ma5 = SMA(close, 5)`
  - `ma10 = SMA(close, 10)`
  - `ma20 = SMA(close, 20)`
- 分类规则：
  - `ma5 > ma10 > ma20`：`bull` 或 `strong_bull`
  - `ma5 > ma10 and ma10 <= ma20`：`weak_bull`
  - `ma5 < ma10 < ma20`：`bear` 或 `strong_bear`
  - `ma5 < ma10 and ma10 >= ma20`：`weak_bear`
  - 其他：`consolidation`
- 强弱判定（对标）：
  - `prev_spread = (MA5[-5] - MA20[-5]) / MA20[-5] * 100`
  - `curr_spread = (MA5[-1] - MA20[-1]) / MA20[-1] * 100`
  - 多头强势条件：`curr_spread > prev_spread and curr_spread > 5`
  - 空头强势条件：对称逻辑

### 5.2 乖离率（严禁追高）

- `bias_ma5_pct = (close - ma5) / ma5 * 100`
- `bias_ma10_pct = (close - ma10) / ma10 * 100`
- `bias_ma20_pct = (close - ma20) / ma20 * 100`
- 关键阈值：
  - `bias_ma5_pct > 5`：标记 `no_chase = true`（严禁追高）

### 5.3 量比与量能状态

- 量比公式（统一口径）：
  - `volume_ratio_5d = volume[-1] / mean(volume[-6:-1])`
- 价格变化：
  - `price_change_pct_1d = (close[-1] - close[-2]) / close[-2] * 100`
- 量能分类阈值：
  - `volume_ratio_5d >= 1.5 and price_change_pct_1d > 0` → `heavy_up`
  - `volume_ratio_5d >= 1.5 and price_change_pct_1d <= 0` → `heavy_down`
  - `volume_ratio_5d <= 0.7 and price_change_pct_1d > 0` → `shrink_up`
  - `volume_ratio_5d <= 0.7 and price_change_pct_1d <= 0` → `shrink_down`
  - 否则 → `normal`

### 5.4 支撑与压制

- MA 支撑容忍度：`2%`
- MA5 支撑：`abs(price-ma5)/ma5 <= 0.02 and price >= ma5`
- MA10 支撑：`abs(price-ma10)/ma10 <= 0.02 and price >= ma10`
- MA20 关键位：`price >= ma20` 时加入支撑参考
- 压制位（对标 v1）：`recent_high_20d = max(high[-20:])` 且 `recent_high_20d > price`

### 5.5 MACD 状态

- `dif = EMA(close, 12) - EMA(close, 26)`
- `dea = EMA(dif, 9)`
- `bar = (dif - dea) * 2`
- 状态分类（优先级由高到低）：
  - `golden_cross_zero`：金叉且 `dif > 0`
  - `crossing_up`：`dif` 上穿零轴
  - `golden_cross`：金叉
  - `death_cross`：死叉
  - `crossing_down`：`dif` 下穿零轴
  - `bullish`：`dif>0 and dea>0`
  - `bearish`：`dif<0 and dea<0`

### 5.6 RSI 状态（以 RSI12 为主）

- RSI 周期：`6/12/24`
- 分类阈值（RSI12）：
  - `>70`：`overbought`
  - `(60, 70]`：`strong_buy_zone`
  - `[40, 60]`：`neutral`
  - `[30, 40)`：`weak`
  - `<30`：`oversold`

### 5.7 综合评分（100 分）

- 维度权重：
  - 趋势 `30`
  - 乖离率 `20`
  - 量能 `15`
  - 支撑 `10`
  - MACD `15`
  - RSI `10`
- 趋势分值（对标）：
  - `strong_bull:30, bull:26, weak_bull:18, consolidation:12, weak_bear:8, bear:4, strong_bear:0`
- 乖离率分值（对标，基于 bias_ma5）：
  - `-3 < bias < 0` → `20`
  - `-5 < bias <= -3` → `16`
  - `bias <= -5` → `8`
  - `0 <= bias < 2` → `18`
  - `2 <= bias < 5` → `14`
  - `bias >= 5` → `4`
- 量能分值（对标）：
  - `shrink_down:15, heavy_up:12, normal:10, shrink_up:6, heavy_down:0`
- 支撑分值：
  - `support_ma5` +5
  - `support_ma10` +5
- MACD 分值（对标）：
  - `golden_cross_zero:15, golden_cross:12, crossing_up:10, bullish:8, bearish:2, crossing_down:0, death_cross:0`
- RSI 分值（对标）：
  - `oversold:10, strong_buy_zone:8, neutral:5, weak:3, overbought:0`

### 5.8 信号分档

- `score >= 75` 且趋势为 `strong_bull/bull`：`strong_buy`
- `score >= 60` 且趋势为 `strong_bull/bull/weak_bull`：`buy`
- `score >= 45`：`hold`
- `score >= 30`：`wait`
- 否则若趋势为 `bear/strong_bear`：`strong_sell`
- 其他：`sell`

## 9. 与你目标文案的映射示例（规则触发）

目标句式：
“今日呈现显著的放量反弹（量比4.1），显示在MA5附近有支撑；但MA10/MA20仍在上方压制，未形成标准多头排列。”

对应触发条件：

- “显著放量反弹”：
  - `volume_status == heavy_up`
  - `volume_ratio_5d >= 1.5`
- “MA5附近支撑”：
  - `support_ma5 == true`
- “MA10/MA20上方压制”：
  - `current_price < ma10` 或 `current_price < ma20`
- “未形成标准多头排列”：
  - `not (ma5 > ma10 > ma20)`

## 10. v1 边界与注意事项

- 本表优先保证“可复现”和“解释性”，不是收益最优参数。
- `volume_ratio_5d` 必须用同一数据源计算，避免实时接口口径漂移。
- 日线样本不足 20 根时，趋势/支撑/MACD/RSI 结果应降级并给出 `data_insufficient` 标记。
- 该映射为 V1 基线，后续需要用样本回放校准阈值。
